INDY OPEN APRS

Web Flasher para ESP8266 / NodeMCU. El firmware se sirve desde el mismo sitio de GitHub Pages para evitar errores de descarga del navegador.

Firmware...

Instalar firmware

Listo. El instalador utilizará firmware/indy-open-latest.bin.
Usa Google Chrome o Microsoft Edge en una computadora compatible con Web Serial. El instalador necesita ejecutarse mediante HTTPS.

Selecciona el puerto COM correspondiente a tu ESP8266 y continúa con el asistente.

Importante: este Web Flasher es únicamente para el ESP8266. No debe utilizarse para programar la Nano TNC / ATmega.

Procedimiento

  1. Conecta el ESP8266 / NodeMCU con un cable USB de datos.
  2. Pulsa Instalar Indy Open APRS.
  3. Selecciona el puerto COM.
  4. Elige si deseas borrar completamente la memoria.
  5. Confirma la instalación.
  6. No desconectes el USB hasta que termine.
  7. Reinicia el equipo y realiza la configuración inicial.

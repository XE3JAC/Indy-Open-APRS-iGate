Procedimiento

  1. Selecciona Indy Open iGate o Indy Open Tracker.
  2. Conecta el ESP8266 / NodeMCU mediante USB.
  3. Pulsa Conectar ESP8266.
  4. Selecciona el puerto correspondiente.
  5. Pulsa Instalar firmware.
  6. No desconectes el equipo hasta que aparezca el mensaje de instalación completada.
Recomendación: utiliza un cable USB de datos y mantén esta ventana abierta durante todo el proceso.
Atención: la configuración anterior del equipo puede borrarse durante la instalación.

Importante: este flasher es únicamente para ESP8266 / NodeMCU. No debe utilizarse para la Nano TNC / ATmega.

Procedimiento

  1. Selecciona Indy Open iGate o Indy Open Tracker.
  2. Conecta el ESP8266 / NodeMCU por USB.
  3. Pulsa Conectar ESP8266.
  4. Selecciona el puerto COM.
  5. Comprueba que se detecte un ESP8266.
  6. Pulsa Instalar firmware.
  7. No desconectes el USB hasta que la consola indique que terminó.
Programación: Web Serial + esptool-js.
Dirección: 0x000000, igual que tu manifiesto actual.
Atención: antes de instalar se borra completamente la memoria flash.
